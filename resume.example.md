---

**Как этим пользоваться.** Скопируй файл в `resume.md` рядом с `package.json` и
перепиши под себя:

```bash
cp resume.example.md resume.md
```

`resume.md` — базовое текстовое резюме. Из него модель берёт факты для ответов
на анкеты работодателя на hh.ru и для ответов бота рекрутёру. Файл в
`.gitignore`, в репозиторий не попадёт.

Резюме в PDF, которое уходит работодателю, задаётся отдельно — во вкладке
«Настройки» у каждой специальности (полный путь к файлу). Имя и фамилию для
подписи в письмах впиши там же, в блоке «Кандидат».
