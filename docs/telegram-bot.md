# Telegram-бот кандидата

Второй, независимый канал: рекрутёр пишет боту сам. Поиск по каналам и первое
сообщение рекрутёру — это user-сессия GramJS (`src/telegram/`), бот их не
заменяет и заменить не может: Bot API не даёт читать историю чужих чатов и не
позволяет писать первым.

Дизайн: [`specs/2026-09-20-telegram-bot-design.md`](superpowers/specs/2026-09-20-telegram-bot-design.md).

## Что нужно один раз

`.env` рядом с `package.json`:

```
TG_BOT_TOKEN=...       # @BotFather → /mybots → API Token
TG_OWNER_CHAT_ID=...   # куда слать пинги; можно отдельный аккаунт
```

`chat_id` подскажет сам бот: запусти его, напиши ему что угодно — он напечатает
в консоль `chat_id этого собеседника: …`.

В `config.json` — блок `bot`: `profile.github`, `profile.telegram`, при желании
`models` и `limits`.

В BotFather (Bot Settings): Group Privacy оставить включённой, Allow Groups —
выключить (бот нужен только в личке), Inline Mode — выключить. Вебхук не
ставить: бот работает на long polling и при найденном вебхуке честно откажется
стартовать.

## Запуск

```bash
npm run bot
```

Круглосуточно — через планировщик задач:

```bash
powershell -ExecutionPolicy Bypass -File scripts/bot-service.ps1
```

## Что бот делает

| Команда | Что |
|---|---|
| `/start` | текст и постоянная клавиатура из четырёх кнопок |
| `/cv` | PDF резюме специальности по умолчанию (дальше — по `file_id`) |
| `/profile` | ссылки из `config.json` |
| `/add_vacancy` | ждёт вакансию: текст, ссылку или файл `pdf`, `docx`, `txt`, `md` |
| `/set_meet` | ждёт дату в формате `дд.мм;чч:мм`, записывает и пингует владельца |

Свободный вопрос — ответ модели строго по фактам резюме. Не по теме — шаблон.

## Границы, которые нельзя размывать

- **У модели нет инструментов.** Ни файлов, ни сети, ни базы. Ключ живёт в
  HTTP-заголовке, а не в промпте.
- **Вакансия из бота не автоодобряется никогда.** `selectAutoApprovals`
  пропускает `source = 'tg-bot'` независимо от тумблера: текст прислал
  незнакомый человек, и он мог быть написан под инъекцию.
- **Файл — это байты.** Разбор идёт в отдельном процессе с таймаутом, тип
  проверяется по расширению, MIME и сигнатуре, файл удаляется сразу.
- **Ссылки — по белому списку.** Иначе `http://127.0.0.1:3000/api/queue`
  превратил бы бота в читалку твоей панели.

## Лимиты

`config.json` → `bot.limits`: 20 ответов модели на чат в сутки, 200 на бота,
не чаще сообщения в 3 секунды, 5 страйков — сутки молчания, 3 записи о
собеседовании на чат в сутки. Счётчики — в `queue.db`, перезапуск их не
обнуляет. `/cv`, `/profile` и `/set_meet` работают всегда: они не стоят денег.
