Вход на hh.ru и ключи сервисов. Всё хранится только на этом компьютере, в data/settings.json — в git этот каталог не попадает.

Вход на hh.ru

Нужен, чтобы программа откликалась на вакансии от твоего имени. Достаточно войти один раз — вход запоминается на этом компьютере.

Откроется отдельное окно браузера с сайтом hh.ru. Введи там логин и пароль (или код из СМС) сам — программа не видит и не сохраняет пароль. Когда вход получится, окно закроется само.

Нейросеть для писем

Пишет письма, личные сообщения рекрутёрам, отвечает на анкеты и заполняет фильтры по резюме.

Берётся на openrouter.ai/keys. Пусто — ключ берётся из файла .env.

Выбранная пробуется первой; если она откажет (лимит, кончились деньги), пойдут запасные из config.json. Платные модели тратят деньги со счёта OpenRouter.

Капча hh.ru

Картинка капчи уходит в сервис распознавания, ответ программа вписывает сама. Не решилось — пищит и ждёт, пока решишь в окне браузера. Риск для аккаунта hh.ru — на тебе.

Отправка без просмотра

Отправленный отклик не отозвать. Советуем сначала поработать вручную.

Автоотклик

Отправлять автоматически, только если скоринг вакансии не ниже этого порога (0–100). Пусто — общий порог minScore из config.json.

Переписка

Бот-секретарь, календарь собеседований, напоминания молчащим рекрутёрам и ящик откликов hh.ru.

Секретарь в личке рабочего аккаунта

Бот отвечает рекрутёрам, которые пишут в личку твоего рабочего Telegram-аккаунта (он задаётся в config.json → bot.secretary.account). Подключается в Telegram: Настройки → Telegram для бизнеса / Chat Automation → Чат-боты → твой бот (токен из TG_BOT_TOKEN). Тумблер действует сразу, без перезапуска бота.

Ящик откликов hh.ru

Читает новые сообщения работодателей и приглашения в чатах откликов. По умолчанию выключено.

Чат открывается без блокировки, работодатель увидит, что сообщения прочитаны; нужна проба: npm run hh:inbox -- --probe-chat.
