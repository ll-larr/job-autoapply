# job-autoapply

Конвейер полуавтоматических откликов на вакансии: сам ищет вакансии на hh.ru,
hr.ge, careerist.ru и в каналах Telegram, оценивает их по твоим навыкам, пишет
сопроводительное письмо моделью через OpenRouter и складывает всё в очередь.
Ты смотришь очередь в панели и решаешь, что отправлять.

Плюс отдельный Telegram-бот-приёмник: рекрутёр пишет боту сам, бот отвечает за
тебя по резюме и складывает вакансию в ту же очередь.

**Ничего не уходит без твоего одобрения**, пока ты сам не включишь автоотклик
во вкладке «Настройки» (там же написано, чем это грозит).

---

## Что нужно

| | |
|---|---|
| Node.js | 24 или новее (`node -v`) |
| Ключ OpenRouter | бесплатный на <https://openrouter.ai/keys>; без ключа вакансии соберутся, но письма будут пустыми |
| Аккаунт hh.ru | логин руками один раз, пароли проект не хранит и не вводит |
| Диск | ~500 МБ на Chromium, который скачает Playwright |
| VPN | нужен, только если твой провайдер блокирует OpenRouter (в России — да) |

Telegram (поиск по каналам и бот) — по желанию, см. [ниже](#telegram-по-желанию).

## Установка

### Windows

1. Поставь Node.js 24+ с <https://nodejs.org> (кнопка LTS, если её версия ≥ 24,
   иначе Current). Проверка — в PowerShell:

   ```powershell
   node -v
   ```

2. Скачай проект и распакуй, либо:

   ```powershell
   git clone https://github.com/ll-larr/job-autoapply.git
   cd job-autoapply
   ```

3. Зависимости и браузер:

   ```powershell
   npm install
   npx playwright install chromium
   ```

Если PowerShell ругается на запуск скриптов — ярлыки `.cmd` в корне проекта уже
запускаются с `-ExecutionPolicy Bypass`, отдельно ничего настраивать не нужно.

### macOS

1. Node.js 24+ — через [Homebrew](https://brew.sh):

   ```bash
   brew install node
   node -v
   ```

2. Проект:

   ```bash
   git clone https://github.com/ll-larr/job-autoapply.git
   cd job-autoapply
   ```

3. Зависимости и браузер:

   ```bash
   npm install
   npx playwright install chromium
   ```

При первом запуске Chromium macOS может спросить разрешение на управление
экраном/доступ к сети — согласись, иначе окно логина не откроется.

**Чего на macOS нет:** ярлыков `.cmd` и скриптов `scripts/*.ps1` (это
PowerShell). Команды `npm run go` и `npm run panel:go` на Mac не работают —
пользуйся обычными `npm run panel`, `npm run search`, `npm run send` из
таблицы [команд](#команды).

## Первый запуск

Одинаково на обеих системах.

1. **Открой панель.**

   Windows: двойной клик по `Панель.cmd` (или `npm run panel`).
   macOS: `npm run panel`.

   Панель живёт на <http://127.0.0.1:4321> и слушает только этот компьютер.

2. **Впиши ключ и выбери модель.** Вкладка «Настройки» → блок «Модель для
   писем». Ключ хранится в `data/settings.json` на твоём компьютере и в git не
   попадает. Модели на выбор: DeepSeek, Claude Sonnet, GLM, бесплатные, либо
   любая другая по её id с OpenRouter. Выбранная пробуется первой, остальные из
   `config.json` остаются запасными.

3. **Впиши имя.** Вкладка «Настройки» → блок «Кандидат». Имя подставляется в
   письма, в сообщения рекрутёрам и в ответы бота. Пусто — модель пишет про
   «кандидата» и подписи не ставит.

4. **Опиши себя.** Там же, во вкладке «Настройки»: специальности, фразы поиска,
   навыки с весами, путь к своему резюме в PDF (полный путь к файлу —
   `C:\Users\имя\Документы\CV.pdf` или `/Users/имя/Documents/CV.pdf`). Кнопка
   «Предложить» заполнит навыки моделью, останется поправить.

5. **Прикрепи резюме.** Резюме берётся только из PDF, который указан в
   «Настройках» у специальности (шаг 4): по нему пишутся письма, отвечает бот
   и заполняются анкеты работодателя. Специальностей несколько — вакансия
   получает резюме своей специальности. Запасного файла нет: нет PDF — письмо
   остаётся пустым, а причина видна в панели. Текст из PDF кешируется в
   `data/resumes/` и обновляется, когда PDF новее кеша.

6. **Поправь `config.json`** под себя: `salaryExpectation`, а если будешь
   поднимать бота — `bot.profile.github` и `bot.profile.telegram`.

7. **Залогинься на hh.ru:**

   ```bash
   npm run login
   ```

   Откроется настоящее окно Chromium. Логин, пароль и капчу вводишь ты — проект
   к ним не прикасается. Куки останутся в `browser-profile/` и переживут
   перезапуски. Для careerist.ru: `npx tsx scripts/login.ts careerist`.

## Повседневная работа

### Windows

В корне проекта три ярлыка, работают двойным кликом:

| Ярлык | Что делает |
|---|---|
| `Панель.cmd` | поднимает панель и открывает её в браузере |
| `Запустить поиск вакансий.cmd` | проверяет ключ и VPN, ищет вакансии, открывает панель |
| `Отправить одобренное.cmd` | отправляет то, что ты одобрил |

Отправки в первых двух нет намеренно: подача отклика необратима и не должна
быть побочным эффектом двойного клика.

### macOS

Ярлыков нет, всё из терминала:

```bash
npm run panel     # панель на http://127.0.0.1:4321
npm run search    # поиск (лучше запускать кнопкой «Найти» в панели)
npm run send      # отправить одобренное
```

Остановить любую команду — `Ctrl+C`. Панель держит процесс открытым, пока не
закроешь окно терминала.

### Как это выглядит в работе

1. В панели жмёшь «Найти», указываешь, сколько вакансий набрать.
2. Вкладка «В ожидании» — карточки с оценкой, совпавшими навыками и готовым
   письмом. Письмо можно править прямо в карточке.
3. «Одобрить» — вакансия уходит во вкладку «Одобрено».
4. «Отправить всё» — отклики уходят с паузами и лимитами площадок.
   **Необратимо**: отклик на hh.ru нельзя отозвать.
5. Вкладка «Отправлено» — что ушло за 30 дней.

Если письма вышли пустыми — кнопка «Дописать письма». Чаще всего причина одна
из трёх: нет ключа, выключен VPN, кончились деньги на счёте OpenRouter. Панель
называет причину прямо.

**Без письма.** Если у одобренной вакансии письма нет, «Отправить всё» сперва
предупредит, сколько откликов уйдёт без сопроводительного письма, — одно
резюме. «ОК» отправляет, «Отмена» не отправляет ничего. В Telegram такое не
уйдёт в любом случае: там письмо и есть сообщение рекрутёру. Автоотклик без
письма не отправляет никогда.

**Остановить.** Пока идёт процесс, рядом с ним появляется красная кнопка:
«Остановить поиск» (правый верхний угол), «Остановить написание писем» (вкладки
«В ожидании» и «Одобрено») и «Остановить отправку» («Одобрено»). Поиск и письма
обрываются сразу, уже готовое остаётся в очереди; отправка дожидается текущей
подачи (она уже уходит работодателю), остальное остаётся одобренным. Остановленный
поиск автоотклик не запускает.

## Команды

Работают одинаково на Windows и macOS.

| Команда | Что делает |
|---|---|
| `npm run panel` | панель одобрения на `127.0.0.1:4321` |
| `npm run search` | поиск вакансий (добавь `-- --limit 20`, чтобы ограничить) |
| `npm run send` | отправка одобренного |
| `npm run stop` | аварийная остановка идущей отправки |
| `npm run status` | что сейчас в очереди |
| `npm run letters` | дописать письма у строк, где они пустые |
| `npm run login` | окно логина на hh.ru (или `careerist` аргументом) |
| `npm run bot` | Telegram-бот-приёмник; с `bot.secretary` в `config.json` отвечает и в личке рабочего аккаунта (секретарь) |
| `npm run followups` | дожимы молчащим рекрутёрам: список, `-- prepare`, `-- send` (тумблер в настройках, по умолчанию выключен) |
| `npm run hh:inbox` | проверка ящика откликов hh.ru, только чтение; `-- --probe` / `-- --probe-chat` — разведка чата |
| `npm run tg:login` | вход в Telegram как пользователь (поиск по каналам) |
| `npm test` | тесты |
| `npm run typecheck` | проверка типов |

Только Windows: `npm run go` (поиск + панель одним скриптом) и
`npm run panel:go` — это обёртки над PowerShell.

## Telegram (по желанию)

Два независимых канала, их не надо путать.

**Поиск по каналам** — вход в твой личный аккаунт (GramJS). Получи `api_id` и
`api_hash` на <https://my.telegram.org> (API development tools), положи в файл
`.env` рядом с `package.json`:

```
TG_API_ID=12345678
TG_API_HASH=...
```

Затем `npm run tg:login` и добавь каналы в панели («Настройки» → Telegram).
Сессия ляжет в `data/telegram.session` — это полный доступ к твоему аккаунту,
никому не показывай.

**Бот-приёмник** — отдельный бот, которому пишут рекрутёры. Токен у
[@BotFather](https://t.me/BotFather), туда же в `.env`:

```
TG_BOT_TOKEN=...
TG_OWNER_CHAT_ID=...
```

`TG_OWNER_CHAT_ID` подскажет сам бот: запусти `npm run bot` и напиши ему — он
напечатает chat_id в консоль. Туда же бот шлёт единственный пинг — о назначенном
собеседовании (если вакансия прикреплялась — с её текстом файлом). Подробности и
лимиты — в [`docs/telegram-bot.md`](docs/telegram-bot.md).

## Где что лежит

| Путь | Что это | В git |
|---|---|---|
| `config.json` | техника: пороги, модели по умолчанию, паузы и лимиты площадок | да |
| `data/settings.json` | ключ OpenRouter, выбранная модель, специальности, навыки, чаты | **нет** |
| `data/queue.db` | очередь вакансий и история отправок | **нет** |
| `browser-profile/` | куки твоих аккаунтов | **нет** |
| `.env` | ключи Telegram, при желании `OPENROUTER_API_KEY` | **нет** |
| `templates/ai-llm-ba.md` | единственный скелет письма: модель дописывает только `{{FIT}}`, остальное идёт дословно; новые черновики делаются на его основе | да |
| `templates/tg-dm.md` | скелет первого сообщения рекрутёру в Telegram: модель пишет строку для `{{VACANCY}}` (название и ссылка на пост) и текст для `{{FIT}}`, сам скелет подставляет код | да |
| `docs/` | разбор вёрстки площадок, спецификации, планы | да |

Каталог `data/`, `browser-profile/` и `.env` перечислены в `.gitignore` —
ключи и куки не уедут в репозиторий даже случайным `git add .`.

## Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| Все письма пустые | нет ключа (впиши в панели) либо выключен VPN |
| `403 Access denied by security policy` | это блок-страница провайдера, а не ошибка ключа — включи VPN |
| `HTTP 402` | кончились деньги на счёте OpenRouter — пополни или выбери бесплатную модель |
| `HTTP 429` | общий лимит бесплатных моделей — подожди или возьми платную |
| `Порт 4321 занят` | панель уже запущена в другом окне |
| hh просит логин при поиске | `npm run login`, профиль протух |
| Отправка встала после пары отказов | предохранитель `maxConsecutiveFailures`: скорее всего капча или сменившаяся вёрстка |

На macOS поиск прокси пропускается сам (он умеет искать только VPN-клиенты
Windows). Если OpenRouter у тебя блокируется, задай адрес прокси явно:

```bash
HTTPS_PROXY=http://127.0.0.1:10809 npm run panel
```
