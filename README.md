# job-autoapply

Конвейер полуавтоматических откликов на вакансии: сам ищет вакансии на hh.ru,
hr.ge, careerist.ru и в каналах Telegram, оценивает их по твоим навыкам, пишет
сопроводительное письмо моделью через OpenRouter и складывает всё в очередь.
Ты смотришь очередь в панели и решаешь, что отправлять.

Плюс отдельный Telegram-бот-приёмник: рекрутёр пишет боту сам, бот отвечает за
тебя по резюме и складывает вакансию в ту же очередь.

**Ничего не уходит без твоего одобрения**, пока ты сам не включишь автоотклик
во вкладке «Настройки» (там же написано, чем это грозит).

## Что нужно

| Зависимость | Для чего и как устанавливается |
|---|---|
| Windows 11 (x64/ARM64) или macOS 14+ (Apple Silicon/Intel) | Поддерживаемые платформы для Chromium из Playwright |
| Windows PowerShell 5.1 или встроенные утилиты macOS (`bash`, `curl`, `tar`, `shasum`) | Запускают установку на своей ОС |
| Node.js 24+ с npm | Лаунчер использует их из `PATH` или скачивает Node.js 24 LTS вместе с npm в `.runtime/` |
| npm-пакеты | `playwright`, `fflate`, `telegram` (GramJS), `undici`, `unpdf`. Для запуска TypeScript и разработки — `tsx`, `typescript`, `@types/node`, `vitest`. Точные версии, транзитивные и платформенные пакеты — в `package-lock.json` |
| Chromium для Playwright | Лаунчер скачивает ревизию под ОС и архитектуру. Под первый запуск оставь около 1 ГБ на Node.js, пакеты и браузер |
| Интернет | Для первого запуска нужен доступ к `nodejs.org`, реестру npm и CDN Playwright |

SQLite входит в Node.js. Git нужен только для `git clone`.

Для входа на hh.ru нужен аккаунт. Ключ [OpenRouter](https://openrouter.ai/keys)
нужен для генерации писем. Если провайдер блокирует OpenRouter, понадобится
VPN или прокси. Telegram подключается [по желанию](#telegram-по-желанию).

## Установка

Скачай ZIP репозитория и распакуй его целиком или выполни:

```bash
git clone https://github.com/<your-username>/job-autoapply.git
cd job-autoapply
```

### Windows

Открой `panel.cmd` или `Панель.cmd` двойным кликом. Лаунчер установит
зависимости и откроет панель в браузере. Встроенный Windows PowerShell
запускается с параметром `-ExecutionPolicy Bypass` для этого процесса.

### macOS

В терминале из папки проекта выполни:

```bash
bash panel.command
```

Когда запустится сервер, открой <http://127.0.0.1:4321>. При наличии права
на исполнение `panel.command` можно открыть двойным кликом в Finder.

При повторном запуске лаунчеры используют уже скачанные файлы. Если
`package-lock.json` изменится, npm-пакеты переустановятся. Playwright
проверяет актуальность Chromium при каждом запуске. Если первая загрузка
прервётся, запусти тот же лаунчер снова.

### Команды npm после установки

Если лаунчер скачал Node.js в `.runtime/`, добавь его в `PATH` текущего
терминала, прежде чем выполнять команды из README. Запусти нужный блок
из корня проекта.

Windows PowerShell:

```powershell
$nodeDir = Get-ChildItem .runtime -Directory -Filter 'node-*-win-*' |
    Where-Object { Test-Path (Join-Path $_.FullName 'node.exe') } |
    Sort-Object Name -Descending | Select-Object -First 1
$env:Path = "$($nodeDir.FullName);$env:Path"
npm.cmd run login
```

macOS:

```bash
export PATH="$(dirname "$(find "$PWD/.runtime" -path '*/bin/node' -print | sort | tail -1)"):$PATH"
npm run login
```

Если Node.js 24+ и npm уже доступны в терминале, можно подготовить проект и
открыть панель командами `npm run setup:panel` и `npm run panel`. В Windows
PowerShell при ограничении на запуск скриптов используй `npm.cmd`.

## Первый запуск

Одинаково на обеих системах.

1. **Открой панель.**

   Windows — двойной клик по `panel.cmd` или `Панель.cmd`.
   macOS — `bash panel.command`.

   Панель живёт на <http://127.0.0.1:4321> и слушает только этот компьютер.

   При первом входе панель проведёт короткое обучение: по очереди подсветит
   кнопки и расскажет, за что они отвечают. Повторить его можно кнопкой
   «❓ Обучение» в правом верхнем углу.

2. **Впиши ключ и выбери модель.** Вкладка «Настройки» → раздел «Аккаунты и
   ключи» → блок «Нейросеть для писем». Ключ хранится в `data/settings.json`
   на твоём компьютере и в git не попадает. Модели на выбор: DeepSeek, Claude Sonnet, GLM, бесплатные, либо
   любая другая по её id с OpenRouter. Выбранная пробуется первой, остальные из
   `config.json` остаются запасными.

3. **Впиши имя.** Вкладка «Настройки» → раздел «Фильтры поиска» → блок «О тебе». Имя
   подставляется в письма, в сообщения рекрутёрам и в ответы бота. Пусто —
   модель пишет про «кандидата» и подписи не ставит.

4. **Прикрепи резюме.** Вкладка «Настройки» → раздел «Фильтры поиска». У
   фильтра нажми «Обзор…» и выбери своё резюме в PDF — файл скопируется в
   `data/resumes/pdf/`, путь подставится сам. По резюме пишутся письма,
   отвечает бот и заполняются анкеты работодателя. Фильтров несколько —
   вакансия получает резюме своего фильтра; новый добавляется кнопкой
   «+ Добавить резюме». Запасного файла нет: нет PDF —
   письмо остаётся пустым, а причина видна в панели. Текст из PDF кешируется в
   `data/resumes/` и обновляется, когда PDF новее кеша.

5. **Заполни фильтр.** Фильтр устроен как вакансия на hh.ru: должность,
   зарплата, опыт, тип занятости, оформление, график, рабочие часы, формат
   работы, навыки и ключевые слова (вакансия проходит, только если одно из них
   есть в её названии). Кнопка «Заполнить с ИИ» по резюме впишет должность,
   ключевые слова, опыт, навыки и зарплату (если она есть в резюме);
   предпочтения вроде графика и формата выбираешь сам. Ничего не выбрано в
   группе — подходит любое значение. Ищется вакансия по должности; другие
   названия той же работы можно добавить в блоке «Искать ещё по другим
   названиям». Затем нажми «Сохранить» внизу вкладки.

6. **Поправь `config.json`** под себя: `salaryExpectation`, а если будешь
   поднимать бота — `bot.profile.github` и `bot.profile.telegram`.

7. **Войди в hh.ru.** Вкладка «Настройки» → раздел «Аккаунты и ключи» → блок
   «Вход на hh.ru» → кнопка «Войти в hh.ru». Откроется настоящее окно Chromium. Логин, пароль, код из
   СМС и капчу вводишь ты — проект к ним не прикасается. Когда вход получится,
   окно закроется само, а в панели появится «✓ Вход выполнен». Куки останутся
   в `browser-profile/` и переживут перезапуски.

   То же из терминала: `npm run login`. Для careerist.ru:
   `npx tsx scripts/login.ts careerist`.

## Повседневная работа

### Windows

Ярлыки в корне проекта работают двойным кликом:

| Ярлык | Что делает |
|---|---|
| `panel.cmd` / `Панель.cmd` | проверяет зависимости, поднимает панель и открывает её в браузере |
| `Запустить поиск вакансий.cmd` | проверяет ключ и VPN, ищет вакансии, открывает панель |
| `Отправить одобренное.cmd` | отправляет то, что ты одобрил |

Отправки в первых двух нет намеренно: подача отклика необратима и не должна
быть побочным эффектом двойного клика.

### macOS

Из терминала:

```bash
bash panel.command # панель на http://127.0.0.1:4321
npm run search    # поиск (лучше запускать кнопкой «Найти вакансии» в панели)
npm run send      # отправить одобренное
```

Остановить любую команду — `Ctrl+C`. Панель держит процесс открытым, пока не
закроешь окно терминала.

### Как это выглядит в работе

1. В панели указываешь, сколько вакансий набрать, и жмёшь «Найти вакансии».
2. Вкладка «В ожидании» — карточки с оценкой, совпавшими навыками и готовым
   письмом. Письмо можно править прямо в карточке.
3. «Одобрить» — вакансия уходит во вкладку «Одобрено».
4. «Отправить всё» — отклики уходят с паузами и лимитами площадок.
   **Необратимо**: отклик на hh.ru нельзя отозвать.
5. Вкладка «Отправлено» — что ушло за 30 дней.

Если письма вышли пустыми — кнопка «Дописать письма». Чаще всего причина одна
из трёх: нет ключа, выключен VPN, кончились деньги на счёте OpenRouter. Панель
называет причину прямо.

**Без письма.** Если у одобренной вакансии письма нет, «Отправить всё» сперва
предупредит, сколько откликов уйдёт без сопроводительного письма, — одно
резюме. «ОК» отправляет, «Отмена» не отправляет ничего. В Telegram такое не
уйдёт в любом случае: там письмо и есть сообщение рекрутёру. Автоотклик без
письма не отправляет никогда.

**Остановить.** Пока идёт процесс, рядом с ним появляется красная кнопка:
«Остановить поиск» (правый верхний угол), «Остановить написание писем» (вкладки
«В ожидании» и «Одобрено») и «Остановить отправку» («Одобрено»). Поиск и письма
обрываются сразу, уже готовое остаётся в очереди; отправка дожидается текущей
подачи (она уже уходит работодателю), остальное остаётся одобренным. Остановленный
поиск автоотклик не запускает.

## Команды

Работают одинаково на Windows и macOS.

| Команда | Что делает |
|---|---|
| `npm run setup:panel` | установить или проверить пакеты и Chromium |
| `npm run panel` | панель одобрения на `127.0.0.1:4321` |
| `npm run search` | поиск вакансий (добавь `-- --limit 20`, чтобы ограничить) |
| `npm run send` | отправка одобренного |
| `npm run stop` | аварийная остановка идущей отправки |
| `npm run status` | что сейчас в очереди |
| `npm run letters` | дописать письма у строк, где они пустые |
| `npm run login` | окно логина на hh.ru (или `careerist` аргументом) |
| `npm run bot` | Telegram-бот-приёмник; с `bot.secretary` в `config.json` отвечает и в личке рабочего аккаунта (секретарь) |
| `npm run followups` | дожимы молчащим рекрутёрам: список, `-- prepare`, `-- send` (тумблер в настройках, по умолчанию выключен) |
| `npm run hh:inbox` | проверка ящика откликов hh.ru, только чтение; `-- --probe` / `-- --probe-chat` — разведка чата |
| `npm run tg:login` | вход в Telegram как пользователь (поиск по каналам) |
| `npm test` | тесты |
| `npm run typecheck` | проверка типов |

Только Windows: `npm run go` (поиск + панель одним скриптом) и
`npm run panel:go` — это обёртки над PowerShell.

## Telegram (по желанию)

Два независимых канала, их не надо путать.

**Поиск по каналам** — вход в твой личный аккаунт (GramJS). Получи `api_id` и
`api_hash` на <https://my.telegram.org> (API development tools), положи в файл
`.env` рядом с `package.json`:

```
TG_API_ID=12345678
TG_API_HASH=...
```

Затем `npm run tg:login` и добавь каналы в панели («Настройки» → Telegram).
Сессия ляжет в `data/telegram.session` — это полный доступ к твоему аккаунту,
никому не показывай.

**Бот-приёмник** — отдельный бот, которому пишут рекрутёры. Токен у
[@BotFather](https://t.me/BotFather), туда же в `.env`:

```
TG_BOT_TOKEN=...
TG_OWNER_CHAT_ID=...
```

`TG_OWNER_CHAT_ID` подскажет сам бот: запусти `npm run bot` и напиши ему — он
напечатает chat_id в консоль. Туда же бот шлёт единственный пинг — о назначенном
собеседовании (если вакансия прикреплялась — с её текстом файлом). Подробности и
лимиты — в [`docs/telegram-bot.md`](docs/telegram-bot.md).

## Где что лежит

| Путь | Что это | В git |
|---|---|---|
| `config.json` | техника: пороги, модели по умолчанию, паузы и лимиты площадок | да |
| `data/settings.json` | ключ OpenRouter, выбранная модель, специальности, навыки, чаты | **нет** |
| `data/queue.db` | очередь вакансий и история отправок | **нет** |
| `browser-profile/` | куки твоих аккаунтов | **нет** |
| `.env` | ключи Telegram, при желании `OPENROUTER_API_KEY` | **нет** |
| `templates/ai-llm-ba.md` | единственный скелет письма: модель дописывает только `{{FIT}}`, остальное идёт дословно; новые черновики делаются на его основе | да |
| `templates/tg-dm.md` | скелет первого сообщения рекрутёру в Telegram: модель пишет строку для `{{VACANCY}}` (название и ссылка на пост) и текст для `{{FIT}}`, сам скелет подставляет код | да |
| `docs/` | разбор вёрстки площадок, спецификации, планы | да |

Каталог `data/`, `browser-profile/` и `.env` перечислены в `.gitignore` —
ключи и куки не уедут в репозиторий даже случайным `git add .`.

## Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| Лаунчер остановился на загрузке | проверь интернет и доступ к Node.js, npm и Playwright CDN, затем запусти лаунчер снова |
| Все письма пустые | нет ключа (впиши в панели) либо выключен VPN |
| `403 Access denied by security policy` | это блок-страница провайдера, а не ошибка ключа — включи VPN |
| `HTTP 402` | кончились деньги на счёте OpenRouter — пополни или выбери бесплатную модель |
| `HTTP 429` | общий лимит бесплатных моделей — подожди или возьми платную |
| `Порт 4321 занят` | панель уже запущена в другом окне |
| hh просит логин при поиске | вход протух — нажми «Войти в hh.ru» в настройках (или `npm run login`) |
| Отправка встала после пары отказов | предохранитель `maxConsecutiveFailures`: скорее всего капча или сменившаяся вёрстка |

На macOS поиск прокси пропускается сам (он умеет искать только VPN-клиенты
Windows). Если OpenRouter у тебя блокируется, задай адрес прокси явно:

```bash
HTTPS_PROXY=http://127.0.0.1:10809 npm run panel
```

## Разработка

```bash
npm test          # 900+ тестов, vitest
npm run typecheck # tsc --noEmit
```

Исходники — TypeScript без сборки, всё запускается через `tsx`. Архитектура и
решения разобраны в комментариях к модулям и в `docs/`.
